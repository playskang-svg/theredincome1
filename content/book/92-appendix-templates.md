title: 부록 3. 글 소재 60개와 첫 줄 모음
kind: 부록
---
<p>소재가 없어서 못 쓰는 날을 위해. 왼쪽은 소재, 오른쪽은 그 소재로 시작하는 첫 줄이다. 첫 줄만 있으면 둘째 줄은 나온다.</p>
<h3>주방</h3>
<ul>
<li>밥솥 패킹 → "삼십 년 밥하면서 오늘 처음 알았어요."</li>
<li>도마 교체 시기 → "도마 언제 바꾸세요? 저는 10년 썼어요."</li>
<li>프라이팬 코팅 → "코팅 벗겨진 팬, 버려야 하는 거 알면서 못 버리는 사람."</li>
<li>식기세척기 린스 → "10년 쓴 식기세척기에 린스 칸이 있는 줄 몰랐어요."</li>
<li>김치통 냄새 → "김치냉장고 냄새가 통 때문인 걸 올해 알았어요."</li>
<li>행주 vs 키친타월 → "행주 삶는 거 포기한 사람 저만 있나요."</li>
<li>들기름 보관 → "들기름 냉장고에 넣으세요? 저는 몰랐어요."</li>
<li>실리콘 뚜껑 → "세 개 사서 두 개 버렸어요."</li>
<li>주방 매트 → "싱크대 앞에 두 시간 서 있으면 발바닥이 말해요."</li>
<li>순한 세제 → "손 트는 거 고무장갑 탓인 줄 알았어요."</li>
<li>수세미 교체 → "수세미 며칠 쓰세요? 저 솔직히 3주."</li>
<li>냉장고 정리 → "냉장고 열면 뭐가 있는지 모르는 사람."</li>
<li>밀폐용기 뚜껑 → "뚜껑만 열 개 남은 사람 손."</li>
<li>전기포트 물때 → "포트 바닥 하얀 거, 구연산 하나로 끝났어요."</li>
<li>가스레인지 vs 인덕션 → "인덕션 바꾸고 후회한 것 하나, 좋은 것 셋."</li>
</ul>
<h3>청소·정리</h3>
<ul>
<li>물걸레 밀대 → "무릎 때문에 바닥 닦는 게 제일 싫었어요."</li>
<li>무선청소기 무게 → "비싼 거 샀다가 무거워서 안 썼어요."</li>
<li>욕실 곰팡이 → "욕실 실리콘 까매진 거, 다들 어떻게 하세요?"</li>
<li>배수구 냄새 → "하수구 냄새 여름마다 올라오는 집."</li>
<li>침구 세탁 주기 → "이불 몇 주마다 빠세요? 솔직하게."</li>
<li>옷장 정리 → "안 입는 옷 버리는 기준이 있으세요?"</li>
<li>현관 신발 → "현관에 신발 몇 켤레 나와 있어요?"</li>
<li>창틀 먼지 → "창틀 청소 1년에 몇 번 하세요?"</li>
<li>세탁기 통세척 → "세탁기 통세척 처음 돌린 날 충격."</li>
<li>건조기 필터 → "건조기 필터 먼지 보고 놀란 사람."</li>
<li>장마철 빨래 → "장마에 빨래 냄새, 어떻게 잡으세요?"</li>
<li>제습제 → "장롱 안 제습제 언제 바꾸는지 모르는 사람."</li>
<li>리모컨 정리 → "리모컨 네 개 있는 집."</li>
<li>약 정리 → "유통기한 지난 약 한 봉지 나왔어요."</li>
<li>서류 정리 → "고지서 어디 두세요? 저는 식탁 위."</li>
</ul>
<h3>중년의 몸</h3>
<ul>
<li>아침 손가락 → "오십 넘으니 아침에 손가락이 뻣뻣해요."</li>
<li>무릎 소리 → "앉았다 일어날 때 소리가 먼저 나요."</li>
<li>밤에 쥐 → "밤에 다리에 쥐 나서 깨는 날이 늘었어요."</li>
<li>돋보기 → "돋보기 세 개 있는 사람."</li>
<li>발 시림 → "양말 두 겹 신던 사람입니다."</li>
<li>허리와 바닥 일 → "바닥에 앉아서 뭘 못 해요."</li>
<li>다리 부음 → "저녁에 다리 붓는 분, 뭐 하세요?"</li>
<li>손목 보호대 → "설거지할 때 손목 보호대 끼는 사람 있어요?"</li>
<li>잠 → "새벽 네 시에 깨는 사람 저만 있나요."</li>
<li>안경 → "안경 어디 뒀는지 하루 세 번 찾는 사람."</li>
<li>걷기 → "하루 몇 걸음 걸으세요? 솔직하게."</li>
<li>건강검진 → "검진 결과지 받고 처음 한 일."</li>
<li>영양제 → "영양제 몇 개 드세요? (효과 말고 개수만)"</li>
<li>어깨 → "어깨 올라가는 각도가 줄었어요."</li>
<li>치아 → "임플란트 하신 분, 몇 개?"</li>
</ul>
<h3>우리 나이, 우리 집</h3>
<ul>
<li>자녀 독립 → "애들 방이 비었어요. 뭘로 쓰세요?"</li>
<li>부모 봉양 → "친정엄마 병원 모시고 다니는 분."</li>
<li>남편 은퇴 → "남편 집에 있는 시간이 늘었어요."</li>
<li>명절 준비 → "명절 음식 몇 가지 하세요? 줄이신 분."</li>
<li>김장 → "김장 몇 포기 하세요? 사 먹는 분도."</li>
<li>용돈 → "오십 넘어 내 용돈이 얼마인지 아세요?"</li>
<li>스마트폰 → "글자 크기 최대로 해 놓은 사람."</li>
<li>친구 → "오십 넘어 새 친구 사귄 분 있어요?"</li>
<li>취미 → "애들 다 키우고 처음 시작한 거 뭐예요?"</li>
<li>부업 → "오십 넘어 돈 벌 궁리하는 사람, 저만 아니죠?"</li>
<li>옷 → "오십 넘으니 옷 사는 기준이 바뀌었어요."</li>
<li>사진 → "휴대폰에 사진 몇 장 있으세요? 저 1만 4천 장."</li>
<li>요리 → "이제 요리가 재미없어진 분."</li>
<li>잠버릇 → "남편이랑 따로 자는 분 많으세요?"</li>
<li>식탁 → "식탁 닦는 거로 하루 마무리하는 사람."</li>
</ul>
<p>60개 중 하루 3개면 20일. 20일 뒤에는 답글에서 소재가 나온다. 경희 씨는 5월부터 소재를 고민한 적이 없다. 사람들이 물어본 것이 다음 글이었다.</p>
