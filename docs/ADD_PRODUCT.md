# 로컬 PDF 판매 사이트(the-pinda-ebook)에 6번째 상품 추가하기

이 저장소의 `dist/threads.pdf`(49쪽, A4)를 `the-pinda-ebook` 프로젝트의 6번째 상품으로 올리는 작업 지시서입니다.
작업은 **`C:\Window_DEV\the-pinda-ebook`** 에서 합니다. 이 저장소(theredincome1)의 Worker는 the.pinda.kr 도메인과 충돌하므로 배포하지 않습니다.

## 1. 로컬 Claude Code에 붙여넣을 지시문

```
the-pinda-ebook 프로젝트에 6번째 상품을 추가해줘. CLAUDE.md를 먼저 읽고 원칙을 지켜.
- PDF는 theredincome1 저장소의 dist/threads.pdf야. https://github.com/playskang-svg/theredincome1 에서 받아 이 프로젝트의 임시 폴더에 두고, R2 버킷 the-pinda-ebooks 에 threads.pdf 로 올려(--remote).
- src/products.js 에 기존 5종과 같은 형식으로 상품 1개를 추가해. 내용은 docs/ADD_PRODUCT.md 의 "상품 등록 내용"을 그대로 쓰고, id/file/img 등 기존 필드 형식은 기존 항목을 따라.
- 판매 페이지에는 "가명"이라는 단어를 쓰지 말고 "재구성" 고지는 유지해. 수익 금액·보장 표현은 판매 문구에 넣지 마.
- 바꾸기 전에 뭘 바꿀지 한 줄로 먼저 말해줘. 키·비밀값은 절대 출력하거나 저장소에 넣지 마.
- 끝나면 npm run dev 로 로컬(ALLOW_MOCK=true)에서 가짜 결제 → 다운로드가 되는지 확인하고, 결제 전 다운로드가 402인지도 확인해.
- 배포(npx wrangler deploy)는 내가 확인한 뒤에 하자.
```

## 2. 상품 등록 내용 (수익 금액·보장·"가명" 표현 없음)

- id: `threads`
- file: `threads.pdf`
- name: 스레드로 시작하는 제휴마케팅, 50대 주부의 8개월 기록
- sub: 글 틀 5개와 30일 체크리스트, 하루 시간표까지. 규칙을 지키며 따라 하는 순서
- price: 29000 (최저가 상품과 같은 가격. 다른 가격을 원하면 여기만 고치면 됨)
- points:
  - 답글 루틴으로 팔로워 0명에서 시작하는 첫 2주
  - 광고처럼 안 보이는 글 틀 5개와 바로 바꿔 쓰는 예문 20개
  - 링크는 본문 말고 첫 답글에: 노출을 덜 깎는 배치와 대가성 문구 쓰는 법
  - 계정 제한을 부르는 행동, 정산·세금·건강보험 확인 순서까지
- who: 스레드로 부업을 시작하려는 50대, 주부, 글쓰기가 부담스러운 분. 이야기는 여러 경험을 바탕으로 재구성한 것이며 결과는 사람과 시기마다 다릅니다 · PDF 약 49쪽

## 3. 직접 올릴 때 (R2)

```
npx wrangler r2 object put the-pinda-ebooks/threads.pdf --file dist/threads.pdf --remote
```

## 4. 알아둘 것

- PDF 안에는 월별 수수료 금액이 나오고 표지 제목에도 "월 100만 원"이 있습니다. 판매 페이지 문구에는 넣지 않았지만, 책 자체는 "이야기는 가명·재구성, 보장 없음" 고지를 본문(들어가며)과 판권 쪽에 유지합니다. 고지를 지우지 마세요.
- 표지 저자는 "더 핀다 편집부"입니다. 박서희 실명 저자로 바꾸려면 책의 재구성 고지와 충돌하지 않는지 먼저 확인하세요.
- 쿠팡파트너스·스레드 정책, 세금·건강보험 기준은 바뀝니다. 책 안의 확인 경로 안내를 반년마다 점검하세요.
